About This System

This DDoS detection system employs a hybrid ensemble approach combining Random Forest and XGBoost classifiers. Both models are trained on the CICIDS2017 dataset and their predictions are combined through weighted voting to achieve superior detection accuracy. The system analyzes 78+ network traffic features to identify malicious DDoS attack patterns in real-time.
